Champ « Formule » — moteur Rust, pas d'Excel à installer

Écrire sa première formule en 2 minutes

Une formule calcule une valeur à partir des autres champs de la même ligne. Elle se recalcule à chaque modification. Pas de code, juste {Nom du champ}, des guillemets et des fonctions comme IF().

Commencer pas à pas
FormuleIF({Statut} = "Payé", "✓", "à relancer")
Résultatsi Statut vaut Payé → ✓ sinon à relancer

1. C'est quoi une formule ?

Un champ de type Formule affiche une valeur calculée. Il n'est pas stocké : il est évalué en Rust à chaque lecture de la ligne. Le contexte est la ligne elle-même : {Nom} vaut la valeur de la colonne « Nom » sur cette ligne, ou vide si la cellule est vide.

  • Lecture seule : on ne tape pas dedans, elle se recalcule.
  • Même ligne uniquement : pas d'accès direct à une autre ligne (utilise un champ Lien/Lookup/Rollup puis une formule dessus).
  • Sans danger : pas de eval JavaScript, pas d'accès réseau.
Astuce : renomme tes colonnes sans espaces accentués pour taper plus vite, mais les accolades gèrent tout : {Prénom}, {Date naissance}, {Montant TTC} sont valides.

2. Premiers pas — ta première formule

  1. Crée un champ Formule : sidebar → + Champ → type Formule.
  2. Tape une expression : commence par = est optionnel, écris directement {Nom}.
  3. Valide : la colonne affiche le résultat pour chaque ligne.

Anatomie d'une formule

IF( {Montant} > 100 , "Gros" , "Petit" )
│   │            │           │
│   └─ champ ────┴─ test ───┴─ deux résultats possibles
└─ fonction

Conversions automatiques

  • Nombre attendu mais texte reçu : " 12.5 " → 12.5, texte non numérique → 0.
  • Texte attendu mais nombre reçu : 42 → "42".
  • Booléen : 0, "", "false", null, tableau vide → false, le reste → true.

Priorité : parenthèses ( ) d'abord, puis * / %, puis + - &, puis comparaisons. En doute, mets des parenthèses.

// Moyenne : parenthèses obligatoires
({Note1} + {Note2} + {Note3}) / 3

// Sans parenthèses : faux !
{Note1} + {Note2} + {Note3} / 3  // divise seulement Note3
Piège + : si l'un des deux côtés n'est pas un nombre, + concatène. Écris 1 + 2 → 3 mais "1" + 2 → "12". Pour forcer l'addition, assure-toi que les deux sont des nombres.

5. Références {Champ}

  • Tape { → l'éditeur propose les noms. Clique pour insérer.
  • Nom exact : {Prénom} ≠ {prenom} mais le moteur est tolérant à la casse pour les fonctions, pas pour les noms.
  • Champ inexistant → vaut vide (pas d'erreur).
  • Champ vide → "" ou null selon le type. Teste avec IF({Mail} = "", "manquant", {Mail}).
// Valeur par défaut si vide
IF({Surnom} = "", {Prénom}, {Surnom})

// Sécuriser un nombre vide → 0
IF({Quantité} = "", 0, {Quantité}) * {Prix}

6. Fonctions — Logique

IF(condition, valeur_si_vrai, valeur_si_faux)

La plus utilisée. Si condition est vraie, renvoie le 2ᵉ argument, sinon le 3ᵉ.

IF({Montant} > 100, "Gros", "Petit")
  • IF({Age} >= 18, "Majeur", "Mineur")
  • IF({Statut} = "Payé", "✓", IF({Statut} = "En retard", "⚠", "…")) — IF imbriqués.
  • IF({Remise} > 0, {Prix} * (1 - {Remise}/100), {Prix})

SWITCH(valeur, cas1, résultat1, cas2, résultat2, …, défaut)

Plus lisible que des IF en cascade quand on teste une même valeur.

SWITCH({Statut}, "Payé", "✓", "En attente", "…", "Brouillon", "⚠", "Inconnu")

Dernier argument = défaut seulement si le nombre total d'arguments est impair. Sans défaut et aucun cas ne matche → vide.

AND(...) OR(...) NOT(valeur)

IF(AND({Age} >= 18, {Pays} = "FR"), "OK", "Non")
  • AND({Actif}, {Stock} > 0) → vrai seulement si les deux vrais.
  • OR({Statut} = "Payé", {Statut} = "Offert")
  • NOT({Archivé}) — inverse.

7. Fonctions — Texte

CONCATENATE(texte1, texte2, …) — alias &

CONCATENATE({Prénom}, " ", {Nom})

Équivalent : {Prénom} & " " & {Nom}. Ignore les valeurs vides.

LEN(texte)

Nombre de caractères (compte les émojis comme 1).

LEN("hello") → 5

LEN({Commentaire}) > 200 → repère les longs textes.

LOWER(texte) UPPER(texte) TRIM(texte)

UPPER("alice") → "ALICE"

TRIM(" hello ") → "hello" — supprime espaces début/fin.

LEFT(texte, n) RIGHT(texte, n) MID(texte, départ, longueur)

  • LEFT("hello", 2) → "he"
  • RIGHT("hello", 2) → "lo"
  • MID("hello", 2, 3) → "ell" — départ à 1.
  • MID("2024-03-14", 1, 4) → "2024" extrait l'année.
LEFT({Réf}, 3) & "-" & RIGHT({Réf}, 4)

REGEX_MATCH(texte, motif) REGEX_EXTRACT(texte, motif)

Regex linéaire, limite 1 Mo. Motif invalide → #ERREUR.

REGEX_MATCH("abc123", "[0-9]+") → true
  • REGEX_MATCH({Mail}, "^[^\s@]+@[^\s@]+\\.[^\s@]+$") → email valide ?
  • REGEX_EXTRACT("REF-2024-042", "([0-9]+)") → "2024" — capture groupe 1, sinon groupe 0.
  • REGEX_EXTRACT({Téléphone}, "0([0-9 ]+)")

Échappe les guillemets : "[0-9]+" suffit, pas besoin de double slash en dehors du JSON.

8. Fonctions — Maths

SUM(...) AVERAGE(...) MIN(...) MAX(...)

Acceptent nombres, tableaux et mélanges. Les vides sont ignorés. AVERAGE() vide → vide.

SUM(1, 2, 3) → 6
  • SUM({Note1}, {Note2}, {Note3})
  • SUM({Lien Montants}) — somme d'un champ lié (tableau).
  • AVERAGE({Q1}, {Q2}, {Q3}, {Q4})
  • MIN({Stock A}, {Stock B})

ROUND(nombre, décimales) ABS(nombre) MOD(a, b)

  • ROUND(2.567, 2) → 2.57 ; ROUND(1234, -2) → 1200
  • ABS(-5) → 5
  • MOD(10, 3) → 1 ; 10 % 3 identique ; division par 0 → vide.
ROUND({Prix} * 1.20, 2)
Calcul en chaîne : ({Prix} - {Remise}) * {Quantité} * 1.20 — mets des parenthèses, le moteur respecte la priorité * / avant + -.

9. Fonctions — Dates

Les dates sont des chaînes YYYY-MM-DD ou YYYY-MM-DD HH:MM:SS. Le moteur comprend aussi 2024-03-14T10:30:00 et les timestamps secondes.

DATETIME_DIFF(date1, date2, unité)

Différence date1 - date2 en seconds | minutes | hours | days | weeks | months | years (singulier ou pluriel). Mois = 30.44 j, année = 365.25 j.

DATETIME_DIFF('2024-01-10', '2024-01-01', 'days') → 9
  • DATETIME_DIFF({Échéance}, TODAY(), 'days') → jours restants (négatif si en retard).
  • DATETIME_DIFF({Fin}, {Début}, 'hours')

DATETIME_FORMAT(date, format)

Formate avec les codes chrono strftime. Défaut %Y-%m-%d. Format invalide (% seul) → "".

DATETIME_FORMAT('2024-01-01', '%d/%m/%Y') → "01/01/2024"
CodeExemple
%djour 01-31
%mmois 01-12
%Yannée 2024
%H:%Mheure:minute
%Ajour semaine
  • DATETIME_FORMAT({Date}, '%B %Y') → « mars 2024 »
  • DATETIME_FORMAT({Date}, '%d/%m/%Y %H:%M')

DATEADD(date, quantité, unité)

DATEADD('2024-01-01', 5, 'days') → "2024-01-06"
  • DATEADD({Début}, 2, 'months')
  • DATEADD({Début}, -1, 'years')
  • Unités : days, weeks, months, years, hours, minutes, seconds.

TODAY() NOW()

  • TODAY() → "2024-03-14" (date locale).
  • NOW() → "2024-03-14T10:30:00+00:00" (UTC RFC3339).
  • DATETIME_DIFF({Échéance}, TODAY(), 'days') — jours restants.

CREATED_TIME() LAST_MODIFIED_TIME()

Vaut la date de création / dernière modif de la ligne si disponible, sinon vide.

10. Fonctions — Tableaux (champs Lien)

Un champ Lien renvoie un tableau de valeurs (ex: plusieurs produits liés). Ces 3 fonctions le manipulent.

ARRAYJOIN(tableau, séparateur)

ARRAYJOIN({Produits}, ", ")

Sans séparateur : ", ". ARRAYJOIN(["a","b","c"]) → "a, b, c" ; ARRAYJOIN(["a","b"], "|") → "a|b".

ARRAYUNIQUE(tableau)

ARRAYUNIQUE(["x","x","y"]) → ["x","y"]

ARRAYCOMPACT(tableau)

Retire null et "". Utile avant SUM ou ARRAYJOIN.

ARRAYCOMPACT(["a", "", null, "b"]) → ["a","b"]
Recette Rollup maison : SUM({Montants liés}) marche déjà (SUM aplatit les tableaux). Pour une moyenne des montants liés : AVERAGE({Montants liés}). Pour compter sans Rollup : LEN(ARRAYJOIN({Liens}, ",")) → 0 si vide.

11. 12 exemples complets — copie-colle

1. Nom complet

Tables : {Prénom}, {Nom}

CONCATENATE({Prénom}, " ", UPPER({Nom}))

Alice + Dupont → Alice DUPONT

2. Remise conditionnelle

IF({Quantité} >= 10, {Prix} * 0.9, {Prix})

10+ unités → -10 %

3. Statut couleur (SWITCH)

SWITCH({Statut}, "Payé", "✅ Payé", "En retard", "⚠ Retard", "Brouillon", "…", "❓")

4. Âge / majorité

IF(DATETIME_DIFF(TODAY(), {Naissance}, 'years') >= 18, "Majeur", "Mineur")

5. Retard en jours

IF({Échéance} = "", "", DATETIME_DIFF(TODAY(), {Échéance}, 'days') & " j de retard")

Vide → vide, sinon « 3 j de retard »

6. Échéance + 30 jours

DATEADD({Début}, 30, 'days')

7. Référence normalisée

UPPER(TRIM({Réf})) & "-" & RIGHT("0000" & {Num}, 4)

" ab-12 " + 7 → "AB-12-0007"

8. Email valide ?

IF(REGEX_MATCH({Mail}, "[^@]+@[^@]+\\.[^@]+"), "OK", "→ corriger")

9. Extraire le code postal

REGEX_EXTRACT({Adresse}, "([0-9]{5})")

"12 rue Paris 75001" → "75001"

10. Panier — total ligne

ROUND(({Prix} - IF({Remise} = "", 0, {Remise})) * {Qté} * 1.20, 2)

11. Liste de produits liés

ARRAYJOIN(ARRAYUNIQUE({Produits}), " • ")

12. Initiales

UPPER(LEFT({Prénom},1) & LEFT({Nom},1))

Alice Dupont → AD

13. Bonnes pratiques

  • Nomme bien : {Prix HT} > {Colonne 3}. La formule reste lisible.
  • Gère le vide : IF({X} = "", 0, {X}) avant un calcul.
  • Décompose : plutôt qu'une formule de 5 lignes, crée 2 champs formules intermédiaires.
  • Commente mentalement : IF(... /* remise */) n'existe pas, mais garde une note à côté du champ.
  • Teste les bords : 0, vide, texte avec accent, date 29/02.
